- **[known-issues.md](known-issues.md)**: open and partly fixed issues, plus every review finding with its fix
- **[state-machines.md](state-machines.md)**: every stateful flow (funding, top-ups, keys) and how it survives crashes
- **[demo-runs/](demo-runs/)**: recorded mainnet runs with explorer links
